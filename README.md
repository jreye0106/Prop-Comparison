NBA Player Analytics & Prop Insights Dashboard
This application provides a modern, data‑driven interface for analyzing NBA player performance, matchup trends, and prop betting insights. It is designed for bettors, analysts, fantasy players, and fans who want fast, visual, and actionable information about any NBA player.

The dashboard delivers season averages, opponent‑specific matchup data, color‑coded deltas, hit‑rate metrics, and recent performance charts — all in a clean, sleek UI optimized for clarity and decision‑making.

What Users Can Expect
1. Fast, Dynamic Player Search
Users can search any NBA player using the top search bar.
The page updates instantly without navigation or reloads.

Example workflow:

Search Kawhi Leonard

Review his analytics

Immediately search LeBron James

The dashboard refreshes with LeBron’s full profile

This creates a seamless, fluid experience for rapid player research.

2. Season Performance Overview
Every player page includes:

Points, rebounds, assists averages

Cleanly formatted season summary text

A centered, uniform card layout

Team colors and logos for visual identity

This gives users a quick snapshot of a player’s baseline production.

3. Matchup‑Specific Analytics
When an opponent is included in the query, the dashboard displays:

Player averages vs that opponent

Season vs matchup deltas

Color‑coded delta badges (green for positive, red for negative)

Hit‑rate metrics specific to the matchup

This allows users to understand how a player performs against a particular team.

4. Recommended Prop Insights
The system identifies the strongest statistical angle (points, rebounds, assists) and provides:

Recommended direction (OVER or UNDER)

Season value

Matchup value

Delta impact

This helps users quickly identify high‑value prop opportunities.

5. Hit Rate Breakdown
Users can evaluate consistency through:

Season hit rate

Matchup hit rate

Last 5 games

Last 10 games

This provides a trend‑based view of reliability.

6. Recent Performance Chart
A horizontal bar chart visualizes:

Recent game outputs

Threshold line for prop comparison

Color‑coded bars (green for over, red for under)

Clean date labels and values

This gives users an immediate sense of momentum and volatility.

7. Full Game Logs
The dashboard includes:

Matchup‑specific game logs

Recent game logs

Clean table formatting

This supports deeper research and historical analysis.
